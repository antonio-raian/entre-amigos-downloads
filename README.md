# Entre Amigos para Windows

Voz, telas e boas conversas.

[Baixar para Windows 10/11 (64 bits)](https://github.com/antonio-raian/entre-amigos-downloads/releases/latest/download/Entre-Amigos-Setup-x64.exe)

Este repositório distribui somente os instaladores. A aplicação se conecta a https://entre-amigos-sigma.vercel.app e precisa de internet.

Para atualizar, feche o aplicativo e execute o instalador mais recente usando o mesmo usuário e a mesma pasta. Não é necessário desinstalar antes.

O instalador ainda não tem assinatura digital. O Windows pode informar que o editor é desconhecido.
